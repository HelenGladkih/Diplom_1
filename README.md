# Diplom_1

# Юнит-тесты для сервиса 'Stellar Burgers' https://stellarburgers.nomoreparties.site
Проект содержит комплексные модульные тесты для API системы заказа бургеров Stellar Burgers. Тесты проверяют базовые модели и бизнес-логику приложения.
Тесты хранятся в директории **tests**.

## 🛠 Технологии
- pytest - основной фреймворк для тестирования
- unittest.mock - создание mock-объектов
- pytest-cov - измерение покрытия кода
- parametrize - параметризованное тестирование

## 📝 Особенности реализации
- Полное покрытие всех ключевых моделей (Bun, Ingredient, Burger)
- Тестирование граничных условий и обработки ошибок
- Независимые тесты с изолированными фикстурами
- Параметризация для проверки различных сценариев
- Четкое разделение тестовых данных и логики

## 📂 Структура проекта
- `data.py` -  тестовые данные и константы
- `conftest.py` - фикстуры pytest
- `tests/` - тестовые модули:
  - `test_bun.py` - тесты модели булочки
  - `test_ingredient.py` - тесты модели ингредиента
  - `test_burger.py` - тесты основной бизнес-логики
  - `test_database.py` - тесты работы с данными

## 🚀 Запуск тестов
# Все тесты с измерением покрытия
`pytest --cov=praktikum tests/`
# Конкретный тестовый модуль
`pytest tests/test_burger.py`
# С генерацией отчета о покрытии  
`pytest --cov=praktikum --cov-report=html tests/`

## 🧪 Структура тестов
## Тесты модели Bun (test_bun.py)
Проверка создания булочки
Получение названия и цены
Обработка невалидных параметров
## Тесты модели Ingredient (test_ingredient.py)
Проверка типа, названия и цены ингредиента
Тестирование граничных значений
## Тесты бизнес-логики (test_burger.py)
Добавление/удаление ингредиентов
Расчет итоговой цены
Формирование чека
Обработка ошибок (отсутствие булочки и т.д.)
## Тесты Database (test_database.py)
Проверка доступных булочек и ингредиентов
Корректность данных в базе
